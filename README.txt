試作資料PDFメーカー

使い方：
1. index.html をブラウザで開くと、写真追加・PDF作成ができます。
2. iPhoneのホーム画面に追加するには、このフォルダ一式をHTTPSのWebサーバーに置いてSafariで開き、共有→ホーム画面に追加を選んでください。
3. GitHub Pagesを使う場合、社内規定を確認してください。アプリは写真を外部へ送信しませんが、Webホスティング自体の利用可否は会社に確認してください。
4. iPhoneの共有メニューで「ファイルに保存」を選びます。

注意：HEIC写真はiPhoneのSafariで通常読み込めますが、ブラウザ環境により異なります。ページを閉じると写真は保持されません。
